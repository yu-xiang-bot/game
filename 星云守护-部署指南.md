## 📦 生产环境部署

### 1. Web服务器部署

#### Nginx配置示例
```nginx
server {
    listen 80;
    server_name your-domain.com;
    
    root /path/to/dist;
    index index.html;
    
    # 启用gzip压缩
    gzip on;
    gzip_types text/plain text/css application/json application/javascript text/xml application/xml application/xml+rss text/javascript;
    
    # 静态资源缓存
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2|ttf|eot)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }
    
    # SPA路由支持
    location / {
        try_files $uri $uri/ /index.html;
    }
}
```

#### Apache配置示例
```apache
<VirtualHost *:80>
    ServerName your-domain.com
    DocumentRoot /path/to/dist
    
    # 启用压缩
    LoadModule deflate_module modules/mod_deflate.so
    <Location />
        SetOutputFilter DEFLATE
    </Location>
    
    # 静态资源缓存
    <LocationMatch "\.(css|js|png|jpg|jpeg|gif|ico|svg|woff|woff2|ttf|eot)$">
        ExpiresActive On
        ExpiresDefault "access plus 1 year"
        Header append Cache-Control "public, immutable"
    </LocationMatch>
    
    # SPA路由支持
    <Directory "/path/to/dist">
        RewriteEngine On
        RewriteCond %{REQUEST_FILENAME} !-f
        RewriteCond %{REQUEST_FILENAME} !-d
        RewriteRule . /index.html [L]
    </Directory>
</VirtualHost>
```

## 🖥️ 桌面应用部署

### 1. Electron打包

#### 安装Electron
```bash
npm install --save-dev electron
npm install --save-dev @types/node
```

#### 创建Electron主进程文件
```javascript
// electron-main.js
const { app, BrowserWindow } = require('electron');
const path = require('path');

function createWindow() {
    const win = new BrowserWindow({
        width: 1200,
        height: 800,
        webPreferences: {
            nodeIntegration: true,
            contextIsolation: false
        }
    });
    
    // 加载游戏
    win.loadFile('dist/index.html');
    
    // 开发模式下打开开发者工具
    if (process.env.NODE_ENV === 'development') {
        win.webContents.openDevTools();
    }
}

app.whenReady().then(createWindow);
```

#### 配置package.json
```json
{
  "main": "electron-main.js",
  "scripts": {
    "electron": "electron .",
    "electron-build": "electron-builder"
  },
  "build": {
    "appId": "com.example.starguardian",
    "productName": "星云守护",
    "directories": {
      "output": "electron-dist"
    },
    "files": [
      "dist/**/*",
      "electron-main.js"
    ]
  }
}
```

#### 打包命令

## 📱 移动端部署

### 1. WebView应用

#### Android WebView集成
```java
// MainActivity.java
public class MainActivity extends AppCompatActivity {
    private WebView webView;
    
    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);
        
        webView = findViewById(R.id.webview);
        webView.getSettings().setJavaScriptEnabled(true);
        webView.getSettings().setDomStorageEnabled(true);
        webView.loadUrl("file:///android_asset/dist/index.html");
    }
}
```

#### iOS WebView集成
```swift
// ViewController.swift
import WebKit

class ViewController: UIViewController {
    var webView: WKWebView!
    
    override func viewDidLoad() {
        super.viewDidLoad()
        
        webView = WKWebView(frame: view.bounds)
        view.addSubview(webView)
        
        if let url = Bundle.main.url(forResource: "dist/index", withExtension: "html") {
            webView.loadFileURL(url, allowingReadAccessTo: url.deletingLastPathComponent())
        }
    }
}
```

### 2. PWA部署

#### 创建Service Worker
```javascript
// sw.js
const CACHE_NAME = 'star-guardian-v1';
const urlsToCache = [
    '/',
    '/main.bundle.js',
    '/assets/images/',
    '/assets/sounds/'
];

self.addEventListener('install', (event) => {
    event.waitUntil(
        caches.open(CACHE_NAME)
            .then((cache) => cache.addAll(urlsToCache))
    );
});

self.addEventListener('fetch', (event) => {
    event.respondWith(
        caches.match(event.request)
            .then((response) => response || fetch(event.request))
    );
});
```

#### 注册Service Worker
```javascript
// 在main.js中添加
if ('serviceWorker' in navigator) {
    window.addEventListener('load', () => {
        navigator.serviceWorker.register('/sw.js')
            .then((registration) => {
                console.log('SW registered: ', registration);
            })
            .catch((registrationError) => {
                console.log('SW registration failed: ', registrationError);
            });
    });
}
```

## ⚙️ 服务器配置

### 1. 环境要求

#### 最低配置要求
- **CPU**: 2核心
- **内存**: 2GB RAM
- **存储**: 10GB 可用空间
- **网络**: 10Mbps带宽

#### 推荐配置要求
- **CPU**: 4核心
- **内存**: 4GB RAM
- **存储**: 50GB SSD

#### HTTPS配置

```nginx
add_header X-Content-Type-Options "nosniff";
add_header X-XSS-Protection "1; mode=block";
```

## 🔧 故障排除

### 1. 常见问题

#### 构建失败
```bash
# 清理缓存
rm -rf node_modules
npm install

# 检查Node.js版本
node --version  # 应该 >= 14.0.0
npm --version   # 应该 >= 6.0.0
```

#### 资源加载失败
- 检查静态资源路径是否正确
- 确认服务器配置正确处理静态文件
- 检查CORS设置

#### 性能问题
- 启用Gzip压缩
- 配置CDN加速
- 优化图片资源
- 启用浏览器缓存

### 2. 更新部署

#### 自动化部署脚本
```bash
#!/bin/bash
# deploy.sh

# 1. 拉取最新代码
git pull origin main

# 2. 安装依赖
npm install

# 3. 构建项目
npm run build

# 4. 备份当前版本
cp -r /var/www/html/current /var/www/html/backup-$(date +%Y%m%d-%H%M%S)

# 5. 部署新版本
rm -rf /var/www/html/current/*
cp -r dist/* /var/www/html/current/

# 6. 重启服务
systemctl reload nginx

echo "部署完成！"
```

#### 回滚脚本
```bash
#!/bin/bash
# rollback.sh

# 恢复到上一个版本
LATEST_BACKUP=$(ls -t /var/www/html/backup-* | head -1)
cp -r $LATEST_BACKUP/* /var/www/html/current/

systemctl reload nginx
echo "回滚完成！"
```
